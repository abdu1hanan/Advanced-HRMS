## What is Employee Track Record?

This is the Super Admin version of track records with full management capabilities — view any employee's monthly report, make edits, and export to Excel.

## How to reach this page

1. Expand **Session Management** in the sidebar
2. Click **Employee Track Record**

## What you can do

| Action | Description |
|--------|-------------|
| View | See any employee's monthly attendance summary |
| Edit | Correct attendance data and deduction amounts |
| Export | Download reports as Excel (.xlsx) files |

## How to view a track record

1. Go to **Employee Track Record**
2. **Select an employee** from the dropdown
3. **Choose a month**
4. Review the attendance summary and salary deduction details

## How to export

1. Select employee and month
2. Click **Export** or the download button
3. An Excel file downloads with the full report

## Tips

- Export monthly reports for payroll preparation
- Review deductions before sharing with finance
- Cross-reference with Attendance Management if numbers seem off
- Employees and Managers see read-only versions — only Super Admins can edit
