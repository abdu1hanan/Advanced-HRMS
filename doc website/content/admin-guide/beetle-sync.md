## What is Beetle Sync?

Beetle Sync is the Super Admin page for managing Slack-based attendance overrides. When employees send corrected session times via Slack (e.g. "signin at 10:00 am"), those requests appear here for your approval.

## How to reach this page

1. Expand **Session Management** in the sidebar
2. Click **Beetle Sync**

## The override approval queue

| Column | Description |
|--------|-------------|
| Employee | Who requested the override |
| Original Time | What the system recorded |
| Requested Time | What the employee wants corrected |
| Message | The Slack message they sent |
| Status | Pending, Approved, or Rejected |

## How to approve an override

1. Go to **Beetle Sync**
2. Review the pending override request
3. Verify the corrected time is reasonable
4. Click **Approve** — the session record is updated
5. The employee receives a notification

## How to reject an override

1. Review the request
2. Click **Reject** if the correction is invalid
3. The employee is notified of the rejection

> **IMPORTANT:** Only approve overrides with valid reasons. Frequent overrides may indicate attendance policy issues.

## Tips

- Check this page daily — pending overrides affect track record accuracy
- Cross-reference with the employee's attendance logs before approving
- Ensure Slack User Mapping is correct so messages are attributed to the right person
