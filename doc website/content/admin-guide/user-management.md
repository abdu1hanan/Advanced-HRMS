## What is User Management?

User Management is where Super Admins create and maintain all user accounts in the system. Every employee, manager, and admin has a record here.

## How to create a new user

1. **Click User Management** in the sidebar
2. **Click Add User** (or the create button)
3. **Fill in the form:**
   - Name and email
   - Role (Employee, Admin, or Super Admin)
   - Department
   - Line Manager (who approves their leave)
   - Expected salary and working hours (optional)
4. **Save** — the user can now log in with their email

> **IMPORTANT:** Set the correct **Line Manager** — this determines who approves the user's leave and who appears in Team Directory.

## How to edit a user

1. Go to **User Management**
2. Find the user in the list
3. Click **Edit**
4. Update fields as needed (role, department, manager, salary)
5. Save changes

## Key fields explained

| Field | Purpose |
|-------|---------|
| Role | Employee, Admin (Manager), or Super Admin |
| Department | Which department the user belongs to |
| Line Manager | Their direct boss — receives leave requests |
| Expected Salary | Used in track record calculations |
| Expected Hours | Standard working hours per day |

## Tips

- Assign managers carefully — this controls the approval workflow
- Deactivate rather than delete users who leave the company
- Verify email addresses — users log in with their email
