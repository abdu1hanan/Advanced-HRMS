## What is Leave Settings?

Leave Settings controls how many leave days each employee gets per year. You can set company-wide defaults and override balances for individual users.

## Company-wide settings

Set the default yearly entitlement for each leave type. For example:

- Casual Leave: 12 days per year
- Sick Leave: 10 days per year

These defaults apply to all new users and reset annually.

## Per-user overrides

Sometimes an individual needs a different allocation (e.g. a senior employee with extra days). Use the override section to set custom balances for specific users.

## How to configure settings

1. **Click Leave Settings** in the sidebar
2. **Set company-wide entitlements** for each leave type
3. **Add user overrides** if needed — select user, leave type, and custom balance
4. **Save changes**

> **IMPORTANT:** Changing entitlements does not retroactively adjust already-used balances. Review individual balances after making changes.

## Tips

- Align entitlements with your company's HR policy document
- Use overrides sparingly — document why a user has a different allocation
- Review settings at the start of each calendar year
