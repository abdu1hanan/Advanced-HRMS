## What is the Admin Dashboard?

The Admin Dashboard is the Super Admin home page. It provides a system-wide overview — total users, pending leave requests, recent activity, and key metrics across the entire organization.

## What you'll find here

- **User statistics** — total employees, managers, and admins
- **Pending leave requests** — system-wide count needing attention
- **Pending overrides** — Slack session overrides awaiting approval
- **Recent activity** — latest system events and notifications

## Daily checklist for Super Admins

1. Check **pending leave requests** — approve or route as needed
2. Review **Beetle Sync overrides** — approve corrected session times
3. Monitor **attendance** — mark any absents that weren't auto-detected
4. Verify **new user accounts** are set up correctly
