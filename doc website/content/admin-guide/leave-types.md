## What are Leave Types?

Leave Types define the categories of time off available in your organization. Each type has its own rules, yearly limits, and balance tracking.

## Common leave types

| Type | Typical use |
|------|------------|
| Casual Leave | General personal time off |
| Sick Leave | Medical or health-related absence |
| Unpaid Leave | Time off without salary |
| Absent | Unexcused absence (often system-generated) |

## How to create a leave type

1. **Click Leave Types** in the sidebar
2. **Click Add Leave Type**
3. **Enter the name** and configure rules
4. **Set yearly entitlement** (days per year)
5. **Save**

## How leave types affect the system

- Employees see available types when applying for leave
- Each type has a separate balance counter on the dashboard
- Leave Settings controls company-wide entitlements per type
- Super Admins can set per-user overrides in Leave Settings

## Tips

- Create types that match your company's leave policy
- Set realistic yearly limits — changes mid-year may need manual balance adjustments
- The "Absent" type is often used by the system for unexcused absences
