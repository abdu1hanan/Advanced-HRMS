## What is this page?

All Leave Requests gives Super Admins a system-wide view of every leave request — pending, approved, rejected, and cancelled. You can act on any request, not just your direct reports.

## What you'll see

| Column | Description |
|--------|-------------|
| Employee | Who submitted the request |
| Leave Type | Category of leave |
| Dates | Start and end dates |
| Days | Number of days requested |
| Status | Pending, Approved, Rejected, Cancelled |
| Manager | Assigned line manager |

## How to manage requests

1. **Click All Leave Requests** in the sidebar
2. **Filter or search** for specific requests
3. **Review details** — click a request to see full information
4. **Approve or Reject** — same as a Manager, but for any user in the system

## When Super Admins act on leave

- A manager is unavailable and requests need urgent processing
- Auditing leave decisions across the organization
- Handling edge cases or policy exceptions
