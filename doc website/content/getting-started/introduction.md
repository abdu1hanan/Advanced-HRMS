## What is BeetleOps HRMS?

BeetleOps HRMS is a web-based Human Resource Management System. It helps your company manage employees, track attendance, handle leave requests, and sync work sessions through Slack — all from a single dashboard with a modern dark interface.

Whether you are an employee checking your leave balance, a manager approving team requests, or a super admin configuring the whole system, BeetleOps gives each person exactly the tools they need.

## Who is this for?

This documentation is written for **everyone who uses BeetleOps HRMS**:

- **Employees** — apply for leave, view attendance, check track records
- **Managers (Admins / Line Managers)** — supervise your team, approve leaves, monitor attendance
- **Super Admins** — configure users, departments, leave policies, holidays, and Slack integration

## What can BeetleOps do?

| Area | What it handles |
|------|----------------|
| Leave Management | Apply, approve, and track leave requests with custom leave types |
| Attendance | Daily check-in/out sessions, absent tracking, company holidays |
| Beetle Sync | Automatic attendance from Slack messages (sign in, sign out, breaks) |
| Track Records | Monthly attendance reports with salary deduction calculations |
| Notifications | Real-time alerts when leave status changes or overrides need approval |
| User Management | Roles, departments, manager-employee hierarchy |
