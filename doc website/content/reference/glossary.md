---
title: Glossary
category: Reference
description: Key terms and definitions used throughout BeetleOps HRMS.
---

## A

**Absent** — A day where an employee did not check in and has no approved leave. May trigger salary deductions.

**Activity Log** — Full-page notification history accessible from the bell dropdown ("See all").

**Admin (Manager)** — A user role for line managers who supervise employees and approve leave.

## B

**Beetle Sync** — The Slack integration that automatically records attendance from chat messages.

**Balance (Leave)** — The number of leave days remaining for a specific leave type in the current year.

## D

**Department** — An organizational unit that groups employees (e.g. Engineering, HR).

**Dashboard** — The home page shown after login, customized by role.

## E

**Employee** — The standard user role for staff who manage their own leave and attendance.

**Entitlement** — The total number of leave days allocated per type per year.

## L

**Leave Request** — A formal application for time off with start date, end date, and leave type.

**Leave Type** — Category of leave — Casual, Sick, Unpaid, Absent, etc.

**Line Manager** — The direct boss assigned to an employee; receives their leave requests for approval.

## O

**Override (Session)** — A request to correct a check-in or check-out time, submitted via Slack and approved by Super Admin.

## S

**Session** — A single attendance record for one day — includes check-in time, check-out time, and status.

**Session Status** — Active, On Break, Absent, or Off Duty.

**Slack User Mapping** — The link between a Slack account and an HRMS user account.

**Super Admin** — The highest role with full system configuration access.

## T

**Track Record** — A monthly attendance summary with salary deduction calculations.

## W

**Webhook** — The Slack API endpoint (`POST /webhook/slack`) that delivers messages to BeetleOps for processing.
