## What is a Track Record?

A Track Record is a monthly summary of an employee's attendance — days present, days absent, leave taken, and any salary deductions. It combines attendance data into a single report.

## What it shows

| Data point | Description |
|-----------|-------------|
| Days present | Working days the employee checked in |
| Days absent | Days marked absent without approved leave |
| Leave taken | Approved leave days in the month |
| Salary deduction | Calculated deduction based on absences |
| Expected salary | Employee's configured salary amount |
| Expected hours | Employee's configured working hours |

## Access by role

| Role | Access level |
|------|-------------|
| Employee | View own track record (read-only) |
| Manager | View track records for team members |
| Super Admin | Full access — view, edit, and export any record |

## Salary deductions

When an employee has unexcused absences, the system calculates salary deductions based on configured rules. The deduction amount appears in the track record report.

> **IMPORTANT:** BeetleOps HRMS does not process payroll. Track Records show calculated deductions for reference — actual salary processing happens outside the system.

## Export

Super Admins can **export track records to Excel** (.xlsx) for reporting and payroll preparation.
