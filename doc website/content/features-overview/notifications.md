## What are notifications?

BeetleOps sends you alerts when something important happens — a leave request is approved, a team member applies for leave, or a Slack override needs your attention. Notifications appear in the bell icon dropdown and optionally via email.

## Notification types

| Event | Who gets notified |
|-------|-------------------|
| Leave request submitted | Line Manager |
| Leave approved | Employee who applied |
| Leave rejected | Employee who applied |
| Leave change requested | Employee who applied |
| Session override submitted | Super Admin |
| Override approved/rejected | Employee who requested |

## Where to see notifications

1. **Bell icon (top bar)** — click to open the dropdown with recent alerts
2. **Activity Log** — full history page (Bell → See all)
3. **Email** — if mail is configured, notifications also arrive in your inbox

## Using the notification dropdown

- **Red dot** on the bell = you have unread notifications
- **All / Unread** filter pills to narrow results
- **Mark all read** button (checkmark icon) to clear unread status
- Click any notification to see details
- **See all** link opens the full Activity Log

## Tips

- Managers should check notifications daily for pending leave approvals
- Super Admins should monitor override request notifications
- Employees receive alerts when their leave status changes — no need to keep checking manually
